# Task list

## Move cards on a board

<!-- rule: task-board -->

**Rule:** Use horizontally scrolling board columns with grouping, drag, and equivalent keyboard actions.

**Why:** A drag alone leaves out keyboard users.

**Do:** Show To do, In progress and Done side by side, with Move to in each card's menu.

**Don't:** Wrap the columns, or let only a drag move a card.

## Put New task beside the title

<!-- rule: task-head -->

**Rule:** Put New task beside the title, with shared task search, grouping, and view controls in one toolbar.

**Why:** The tasks start close to the title, and the filters stay when the view changes.

**Do:** End the title row with New task, and put Search, Group by and View under it.

**Don't:** Give New task its own row, or each view its own search.
