# Microcopy and tone

## Name the current state

<!-- rule: state-not-destination -->

**Rule:** Give a control a name for its current state, and change the name when the state changes.

**Why:** A checked switch with the name “Turn off” tells the next action, not the current state.

**Do:** Name the checked switch “In-app notifications, on.”

**Don't:** Name the checked switch “Turn off in-app notifications.”

**Except:** An icon-only toggle can also add the result: “Theme: Dark. Switch to light.”
