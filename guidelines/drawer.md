# Drawers

## One-record drawer

<!-- rule: one-record -->

**Rule:** Open a drawer to view or change one record without leaving its list.

**Why:** Closing the drawer returns the user to the opened row.

**Do:** Open one for a quick edit, a new key, a filter, or the detail of a row.

**Don't:** Open one for a long form, several steps, or a view with its own address and Back.

**Except:** A question with two answers uses confirm, not a drawer.

## Drawer or page

<!-- rule: drawer-or-page -->

**Rule:** Use a page to edit more than one group, and a drawer for one short change.

**Why:** Several groups need room to move between them and check them before saving.

**Do:** Edit roles and per-unit switches on a page, under a way back to the list.

**Don't:** Edit the same groups stacked in one narrow drawer over the list.

**Except:** Change one field inline, without a panel. A drawer can show read-only groups.

## Grouped content

<!-- rule: no-cards -->

**Rule:** Group drawer content under headings. Never put a card in a drawer.

**Why:** The drawer already has an edge and a raised surface, so cards add boxes with no use.

**Do:** Use three groups, with a heading over each group's rows and one line between groups.

**Don't:** Put each group in a card.

## Header and group dividers

<!-- rule: three-lines -->

**Rule:** Add a line below the header and between groups. Leave the footer with no fill and no line.

**Why:** The header line marks the scrolling body. Group lines separate content. Actions share the panel surface.

**Do:** Separate the header and the groups.

**Don't:** Add a line between every row.

## Spaced label rows

<!-- rule: rows -->

**Rule:** Put each value beside its label, and separate rows with space.

**Why:** In a drawer up to 560px wide, labels and values stay together at any zoom without row lines.

**Do:** Put a short value beside its label, such as `Status: Active`.

**Don't:** Put the value at the far edge, with row lines to guide the eye back.

**Except:** On a phone, put each label above its value. Put amounts and other figures compared down the panel in a right-aligned `table()`.
