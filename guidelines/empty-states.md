# Empty states

## Explain what is missing and show the next step

<!-- rule: next-action -->

**Rule:** If there is no content, use the kit’s `emptyState()` or React `EmptyState`. Say what is missing. Give an action that helps the reader continue. Inline “no matches” text in a dropdown or command palette is a result message, not an empty state.

**Why:** A blank area can leave readers unsure if there is no content or if the page failed.

**Do:** Show “No projects yet” with a “Create project” action. Use the kit’s existing spacing and illustration.

**Don't:** Show “Nothing here” without an action.
