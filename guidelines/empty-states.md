# Empty states

## Explain what is missing and show the next step

<!-- rule: next-action -->

**Rule:** Use the kit’s EmptyState when no content is available, clearly explain what is missing, and provide an action that helps the reader continue.

**Why:** A blank area can make readers unsure whether there is no content or the page has failed.

**Do:** Show “No projects yet” with a “Create project” action. Use the kit’s existing spacing and illustration.

**Don't:** Show “Nothing here” without an action.
