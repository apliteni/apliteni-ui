Adopt the apliteni-ui design system across this entire app and replace the current styles.

1. Load it by adding <link rel="stylesheet" href="https://ui.apli.tech/assets/kit.css">
   (or: npm i @apliteni/apliteni-ui && import '@apliteni/apliteni-ui/css').
   Set <html data-theme="dark"> or <html data-theme="light">. You may also set data-accent="phoenix|ocean|emerald".

2. Replace every hardcoded colour, spacing value, and radius with the kit's CSS variables:
   --bg, --surface-2, --surface, --bg-elevated, --surface-3 (the elevation ladder,
   from lowest to highest), --text, --dim, --border, --accent, --accent-strong,
   --radius-*, --dur-*, and --ease. Do not use raw hex colours or px values for these.
   Do not add shadows. A surface shows its elevation through its place on the ladder
   and a 1px --border line. The --shadow-* variables are deprecated and resolve to none.

3. Restyle the app with the kit's classes instead of custom CSS:
   buttons  → .ui-btn + .ui-btn--primary|--secondary|--ghost|--danger (+ --sm|--lg)
   inputs   → .ui-input / .ui-select inside .ui-field with .ui-field__label
   cards    → .ui-card    badges → .ui-badge--live|--soon|--info|--danger
   tables   → .ui-table--hover|--zebra|--dense    toggles → .ui-seg / .ui-switch
   nav / drawer / dropdown / callout / toast / code → the matching .ui-* classes

4. Keep the markup as framework-agnostic HTML: use plain CSS, with no component library and no build step.

5. Change only the visual layer. Preserve all content and behaviour, then verify both dark and light themes.

Vocabulary: https://ui.apli.tech/assets/kit.css — examples: https://ui.apli.tech/storybook/
