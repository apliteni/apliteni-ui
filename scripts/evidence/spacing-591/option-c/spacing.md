# Spacing

## Space by role

<!-- rule: roles -->

**Rule:** Put 8px under a title, 12px under a control row, 20px between sections and 32px under the page head.

**Why:** Most pages use these gaps today, so the rule moves the fewest pages.

**Do:** Keep 32px under a page title that has no introduction.

**Don't:** Write 36px under a toolbar to give an empty list more room.

## Stack control rows closer

<!-- rule: control-rows -->

**Rule:** Put 8px between two control rows that narrow the same block.

**Why:** Both rows act on one table, so they sit closer to each other than to it.

**Do:** Put the table 12px under a view strip that sits 8px under the filters.

**Don't:** Set the strip as far from the filters as the table is.

## Wrap on the scale

<!-- rule: wrapped-rows -->

**Rule:** Keep a wrapped control row's lines 8px apart, and 20px on a touch phone.

**Why:** Elsewhere the lines sit a step tighter than the 12px under the row.

**Do:** Wrap a toolbar 8px apart, where it wraps 10px apart today.

**Don't:** Write a gap that falls between two scale steps.

## Start controls on the column edge

<!-- rule: column-edge -->

**Rule:** Start every control row's box on the page column's edge.

**Why:** One left edge keeps the page on one grid.

**Do:** Leave the view strip's first label 16px in, over the table's first column.

**Don't:** Indent a filter row from the page title.

**Except:** The view strip wraps 4px apart; its tabs already reach the tap floor.
